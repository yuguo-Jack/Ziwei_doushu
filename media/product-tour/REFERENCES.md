# 30秒版剪辑参考

本轮查看了[Linear官方《Introducing Linear For Agents》](https://www.youtube.com/watch?v=sbwOQV5zY34)和[Raycast for Windows官方发布页](https://www.raycast.com/windows)，参考其短句、界面特写、动静反差和连续动作衔接。它们是审美参考，不把网络传播表现当作本片效果保证。

本片采用140BPM、70拍、30秒固定时长，9个镜头组内进一步拆成短动作段，对应8个导航章节。开场两句提问快速建立主题；品牌短揭示后依次用界面特写、依据链和连续追问展示价值；最后用克隆/安装/登录/提问的步骤带入使用。

主要转场为快速方向推移与金色遮幅，关键品牌时刻使用圆形展开。古金、青玉、深墨与中文宋体继续取自根目录DESIGN.md；大标题与镜头变化负责冲击，正文只保留短句。完整安装命令留在README，30秒版交代操作顺序与入口。

本片画面由项目自己的动效和已公开的虚构示例界面组成，旁白来自公开文案，音乐、鼓点和过渡音由本项目确定性合成。
