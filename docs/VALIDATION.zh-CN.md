# 验证范围

本轮在Windows、系统Python 3.12、Node 24和现有CUDA环境中，从真实Git克隆到带空格的新目录，按本轮修订执行`full`语义安装。三个固定源仓库重新获取，两个Node项目分别`npm ci`；原文库、城市库、语义向量、全部77年案例、候选库、同盘索引和网页重新构建。

模型和77个原始压缩包从已有文件逐个核SHA后复用，Python依赖由安装器检查并复用已安装版本。没有复制现成数据库、向量索引或个人记录；这验证全量构建配方，不冒称在第二台空白系统重新安装了Python/Cairo或重新下载全部权重。CPU安装路径已提供，性能取决于实际机器。

本轮发现并修复Windows重复监听本机端口的风险、跨工作区编码器冲突、旧Windows模型路径分隔符的误判、缺失浏览器会话造成的持续读取状态、模型清单选择过时、候选构建参数未传递和复用向量时缺少长度审计的问题。

常用检查从项目根目录执行：

```powershell
python -X utf8 tools/test_codex_review.py
python -X utf8 -m unittest discover -s tests -v
python -X utf8 ziwei.py doctor --experience
python -X utf8 tools/evaluate.py
python -X utf8 scripts/check_release.py
```

`doctor --experience`不发起模型回答，不消耗回答额度；另用安装文档中的`chat ask`或网页实际提问验证网络、模型和账号额度。`doctor --deep`增加模型SHA和数据库完整性校验。`core`或关键词安装只能验自己的所选范围，不能据普通doctor通过声称完整体验。

CI覆盖Windows/Linux单元检查、网页构建与Ubuntu核心词检索构建，不下载大模型、不跑77年全量重建、不使用私人Codex登录。平台支持以实际验证范围为准。完整功能和固定资料可复现，私人记录、浏览器偏好、账号权限及模型逐字回答不会随源码复制。

这些检查验证指定计算、来源、程序与交互行为，不证明任意自然语言都已有参数映射，也不证明传统断语的预测有效性。网站私有评分、专属断语、小限子层、若干流派与未收古籍见README和来源说明。
