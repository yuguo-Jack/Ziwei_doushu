# 验证范围

首个公开版本准备时，对既有工作区复核了会话竞争、停止/重试、草稿保留、中文/ISO日期、主题/合盘关系切换、原典所属领域、引用校验与公开界面的代码隐藏。已有47项会话/解析回归、13项真实计算与检索、11组页面操作以及两轮真实网页Codex回答通过；固定回答/故障模拟与实际模型回答分别记录。截图均使用虚构示例。

公开仓库新增固定来源校验、安装计划、技能迁移与发布保护检查，并提供CI。发布前还要从干净的Git内容在新目录执行核心安装、真实排盘和词检索；不能把已存在的大库复制过去就称为从零构建。

常用检查：

```powershell
python -X utf8 tools/test_codex_review.py
python -X utf8 -m unittest discover -s tests -v
python -X utf8 ziwei.py doctor
python -X utf8 scripts/check_release.py
```

`doctor --deep`另校验模型SHA和数据库完整性，耗时更长。core/关键词安装明确未请求的功能会标为未安装。公开CI不使用真实个人账号发起Codex调用，也不把测试替身计为模型实答。

这些检查验证指定计算、来源、程序和交互行为，不证明任意自然语言都有参数映射，也不证明传统断语的预测效度。网站私有评分、专属断语、小限子层、若干流派与未收古籍仍见README和来源说明。
